# VoiceNote Pro — Запуск

## Что это
Telegram Mini App для голосовых заметок с AI-структуризацией.
React (фронтенд) + Node.js/Hono (бэкенд) + SQLite.

## Нужно
- Node.js 18+
- Anthropic API Key (обязательно для AI функций)

## Быстрый старт

```bash
# 1. Настроить бэкенд
cd backend
cp .env.example .env
# Открой backend/.env и вставь ANTHROPIC_API_KEY
cd ..

# 2. Установить зависимости (фронт + бэк)
npm install
npm run install:all

# 3. Запустить (фронт + бэк одновременно)
npm run dev
# Фронтенд: http://localhost:5173
# API:       http://localhost:3001
```

## Раздельный запуск

```bash
# Только бэкенд
npm run dev:backend

# Только фронтенд
npm run dev:frontend
```

## Docker

```bash
docker-compose up -d
# Открой http://localhost
```

## Нужные ключи

| Ключ | Где взять | Обязателен |
|------|-----------|------------|
| ANTHROPIC_API_KEY | console.anthropic.com | Да |
| TELEGRAM_BOT_TOKEN | @BotFather | Нет |
| FRONTEND_URL | (для CORS, по умолчанию http://localhost:5173) | Нет |

## Используемая модель

По умолчанию используется `claude-haiku-4-5`.
Можно сменить через переменную `CLAUDE_MODEL` в `backend/.env`.
